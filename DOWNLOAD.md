# Como baixar o GameDev AI Assistant

Este ambiente de revisão não aceita arquivos binários anexados. Para baixar o projeto:

1. Clique em **Criar PR** no canto superior direito.
2. Abra o pull request criado no GitHub.
3. Clique em **Code**.
4. Clique em **Download ZIP**.

O ZIP baixado conterá a pasta `gamedev-ai-assistant/` completa.

Também é possível clonar usando o endereço exibido pelo botão **Code**:

```bash
git clone URL_DO_REPOSITORIO
```

Depois, entre na pasta:

```bash
cd DASHBOARD/gamedev-ai-assistant
```
